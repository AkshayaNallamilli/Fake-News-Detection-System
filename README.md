# Fake News Detection System

A machine-learning-based web application that classifies news text as **REAL** or **FAKE**. The project uses TF-IDF text features, three classifiers, and majority voting to produce a final prediction through a Streamlit interface.

## Features

- **Three input modes**
  - Title Only
  - Article Only
  - Title + Article
- **Three machine-learning models**
  - Logistic Regression
  - Linear Support Vector Machine (Linear SVM)
  - Random Forest
- **Text feature extraction:** TF-IDF with unigram and bigram features
- **Dimensionality reduction:** Truncated SVD with 200 components for the Random Forest pipeline
- **Majority voting:** combines the predictions of all three models
- **Model comparison and evaluation:** accuracy, precision, recall, F1-score, and confusion matrices
- **Visual outputs:** model-performance comparison, class distribution, and confusion-matrix plots

## How It Works

1. Load and clean the WELFake dataset.
2. Remove duplicate title/article pairs and split the data into training, validation, and test sets.
3. Expand each split into the supported input formats: title only, article only, and title plus article.
4. Fit a TF-IDF vectorizer on the training text and transform validation/test text.
5. Train Logistic Regression and Linear SVM on TF-IDF features.
6. Apply Truncated SVD to TF-IDF features and train Random Forest on the reduced features.
7. Compare individual model results and calculate the final majority-voting prediction.
8. Use the Streamlit application to submit news text and view individual predictions, the final label, and model agreement.

**Label mapping used by this project:**
- `0` = REAL
- `1` = FAKE

> **Important:** The model's output is a text-classification result, not proof that a news story is true or false. Verify important claims using trustworthy sources. The displayed model agreement is the proportion of models supporting the majority result; it is not a probability that the result is correct.

## Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd fake-news-detection
```

Create and activate a virtual environment (recommended):

**Windows**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install pandas scikit-learn joblib matplotlib streamlit
```

## Dataset Setup

1. Download the WELFake dataset from the source you are permitted to use.
2. Place the CSV in the project root and name it `WELFake_Dataset.csv`.
3. Confirm that it contains these columns: `title`, `text`, and `label`.

The preparation script expects `WELFake_Dataset.csv` in the root directory. It keeps the `title`, `text`, and `label` columns, cleans missing text values, removes rows where both title and article are empty, filters labels to `0` and `1`, removes duplicate title/article pairs, shuffles the data, and creates stratified train/validation/test splits.

The code uses `0 = REAL` and `1 = FAKE`. Confirm that your downloaded dataset uses this same mapping before training; otherwise, update the mapping consistently in the preparation, training, and application scripts.

## Run the Project

Run these commands from the project root.

### 1. Prepare the dataset

```bash
python prepare_dataset.py
```

This creates the `prepared_data/` directory with the cleaned dataset and three data splits.

### 2. Train and evaluate the models

```bash
python train_model_v3_plots.py
```

This creates the `models_v3/` directory, saves the TF-IDF vectorizer and trained models, writes validation/test metrics to CSV files, and generates plots.

Training can take some time depending on your dataset and computer.

### 3. Launch the web application

```bash
streamlit run app_v3.py
```

Open the local URL printed by Streamlit in your browser.

**Run order:** dataset preparation → model training → Streamlit application.

## Evaluation

The training script reports these metrics for each model:

- **Accuracy:** fraction of predictions that are correct.
- **Precision:** fraction of predicted positive-class examples that are positive.
- **Recall:** fraction of positive-class examples correctly identified.
- **F1-score:** harmonic mean of precision and recall.

It also saves confusion matrices and a comparison chart. Actual scores depend on the dataset and training run; check the generated files in `models_v3/` rather than assuming a fixed accuracy.

## Limitations

- Predictions depend on patterns learned from the training dataset and may be wrong for unfamiliar topics, recent events, satire, or misleadingly written articles.
- Text-only classification does not independently verify claims against live sources.
- The majority result can be wrong even when all models agree.
- Dataset label quality, duplicate content, and differences between training and real-world news can affect performance.

## Future Improvements
