# Fake News Detection System

A machine-learning-based web application that classifies news text as **REAL** or **FAKE**. The system uses TF-IDF text features, three machine-learning classifiers, and majority voting to generate a final prediction through a Streamlit interface.

## Features

- **Three input modes:** Title Only, Article Only, and Title + Article
- **Logistic Regression**
- **Linear Support Vector Machine (Linear SVM)**
- **Random Forest**
- **TF-IDF feature extraction** using unigram and bigram features
- **Truncated SVD** with 200 components for the Random Forest pipeline
- **Majority voting** across the three classifiers
- **Model evaluation:** accuracy, precision, recall, and F1-score
- **Visualizations:** confusion matrices, model-performance comparison, and test-set class distribution

## Dataset

This project uses the **WELFake dataset**.

**Download the dataset from Kaggle:**  
https://www.kaggle.com/datasets/saurabhshahane/fake-news-classification

### Dataset setup

1. Open the Kaggle link above and download the dataset.
2. Extract the downloaded files if necessary.
3. Place `WELFake_Dataset.csv` in the root directory of this project, alongside `prepare_dataset.py`.
4. Ensure the CSV contains the columns `title`, `text`, and `label`.

The dataset is **not included in this GitHub repository** because of its large file size. Download it from Kaggle before running the project.

### Label mapping used by this project

- `0` = REAL
- `1` = FAKE

**Important:** Check the labels in the downloaded dataset before training. The preparation and training scripts in this repository expect `0 = REAL` and `1 = FAKE`. If your downloaded version uses the opposite mapping, update the code consistently before training.

## How It Works

1. Load the WELFake dataset.
2. Clean missing text values and remove empty and duplicate title/article pairs.
3. Shuffle the data and create stratified training, validation, and test splits.
4. Create three input formats: title only, article only, and title plus article.
5. Convert text into numerical features using TF-IDF with unigrams and bigrams.
6. Train Logistic Regression and Linear SVM using TF-IDF features.
7. Reduce TF-IDF features with Truncated SVD and train the Random Forest model.
8. Evaluate the models and calculate a majority-voting result.
9. Use the Streamlit web application to classify news text and view individual model predictions and model agreement.

> **Note:** This application classifies text based on patterns learned from its training data. Its output is not independent proof that a news story is true or false. Model agreement indicates how many models support the final prediction; it is not the probability that the prediction is correct.

## Installation

Clone the repository:

```bash
git clone https://github.com/AkshayaNallamilli/Fake-News-Detection-System.git
cd Fake-News-Detection-System
```

(Optional) Create and activate a virtual environment.

**Windows:**

```cmd
python -m venv .venv
.venv\Scripts\activate
```

Install the required libraries:

```bash
pip install pandas scikit-learn joblib matplotlib streamlit
```

## Run the Project

Run all commands from the project root directory.

### Step 1: Download the dataset

Download `WELFake_Dataset.csv` from the Kaggle dataset page linked above and place it in the project root.

### Step 2: Prepare the dataset

```bash
python prepare_dataset.py
```

This creates the `prepared_data/` directory containing the cleaned dataset and the training, validation, and test splits.

### Step 3: Train and evaluate the models

```bash
python train_model_v3_plots.py
```

This creates the `models_v3/` directory, saves the vectorizer and trained models, writes evaluation results to CSV files, and generates plots. Training time depends on your computer and dataset size.

### Step 4: Launch the Streamlit application

```bash
streamlit run app_v3.py
```

Open the local URL shown in the terminal to use the application.

**Execution order:** Download dataset → prepare dataset → train models → run the Streamlit app.

## Evaluation Metrics

The training script reports:

- **Accuracy:** proportion of all predictions that are correct.
- **Precision:** proportion of positive predictions that are correct.
- **Recall:** proportion of actual positive cases correctly identified.
- **F1-score:** harmonic mean of precision and recall.

Confusion matrices and model-comparison plots are saved in `models_v3/plots/`. Check the generated evaluation files for the actual results from your run; performance may vary with dataset version and training conditions.

## Limitations

- Predictions may be inaccurate for recent events, unfamiliar topics, satire, or text unlike the training data.
- The application does not independently verify claims against live news sources.
- Dataset quality, label conventions, duplicates, and topic bias can affect performance.
- Majority voting can still produce an incorrect result, even if all models agree.
